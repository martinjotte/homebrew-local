# Martinjotte Local

## How do I install these formulae?

`brew install martinjotte/local/<formula>`

Or `brew tap martinjotte/local` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "martinjotte/local"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
